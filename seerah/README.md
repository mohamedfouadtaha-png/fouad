# السيرة النبوية — تطبيق موبايل (PWA)

تطبيق مبسط للسيرة النبوية: شجرة النسب والأهل، أمهات المؤمنين، الصحابة، أحداث السيرة، الغزوات، وما لا يسع المسلم جهله، مع اختبار قصير وبحث.

- يعمل على أي موبايل من المتصفح، ويمكن تثبيته كتطبيق (Add to Home Screen) ويعمل بدون إنترنت بعد أول فتح.
- كل المحتوى في `data-people.js` (الأشخاص والشجرة) و`data-seerah.js` (الأحداث والغزوات والأسئلة) — لإضافة شخص أو تعديل نبذة عدّل هذين الملفين فقط.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحات |
| `styles.css` | التصميم (فاتح/داكن) |
| `app.js` | الشجرة، اللوحات، البحث، الاختبار |
| `sw.js` + `manifest.webmanifest` | التثبيت والعمل بدون إنترنت |
